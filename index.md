# DMD1 Backup

DMD1 Backup is a personal backup application operated by Matthew Maune.

It uses rclone to read selected research files from the owner's
Google Drive and download copies to the owner's Windows computer.
Restic creates encrypted backups on an external storage device.

The application requests read-only Google Drive access. It does
not edit or delete the original Google Drive files.

This application is for the owner's personal use and is not
offered as a public backup service.
